How the production version works

1

WhatsApp Business API webhook — every incoming message hits an n8n webhook with the sender, text, and message type (text, button reply, list selection).

2

n8n intent router — classifies intent: menu/catalog, booking, hours/location, or human. Booking intent checks real table availability before confirming.

3

LLM with business knowledge — replies are drafted with the menu, hours, and policies as context; guardrails prevent invented dishes, prices, or slots.

4

Rich WhatsApp replies — interactive buttons and lists (menu categories, time slots) sent back through the API; bookings land in the reservation sheet/CRM.

5

After-hours + handoff — outside hours the bot takes the request and queues it; on complaints or "call me" it alerts staff with the full transcript.

n8n workflow blueprint

Import-ready workflow: WA webhook → Switch(intent) → OpenAI → WA reply → Sheets/CRM log, with after-hours branch and staff-alert escalation.
